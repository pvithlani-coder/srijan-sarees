# Contributing to Srijan Sarees

## Workflow

1. **Never push directly to `main`**
2. Create a branch: `git checkout -b feature/your-change`
3. Make changes in `public/`
4. Push and open a Pull Request
5. Netlify will post a **preview URL** on the PR — test it
6. Get review/approval, then merge

## Branch naming

- `feature/add-instagram-tab` — new features
- `fix/watermark-clipping` — bug fixes
- `style/catalog-card-spacing` — visual tweaks

## Files

All editable files are in `public/`:
- `catalog.html` — customer-facing page
- `admin.html` — admin portal (password protected)
- `logo.png` — Srijan Sarees logo

Do not commit large images or test files to the repo.
